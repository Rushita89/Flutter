
# InstaClone

InstaClone is a Flutter application developed using Dart.

## Project Folder Structure

### 1. lib/
The `lib/` folder contains the main Dart source code of the application. Files such as `main.dart` contain the app entry point, widgets, UI layouts, and application logic.

### 2. android/
The `android/` folder contains Android-specific configuration files and native code. It is used to configure, build, and run the Flutter application on Android devices.

### 3. ios/
The `ios/` folder contains iOS-specific configuration files and native code. It is used to configure, build, and run the Flutter application on iPhones and other supported Apple devices.

### 4. test/
The `test/` folder contains automated tests for the application. These tests help verify that widgets and application functionality work as expected.

## Technologies Used
- Flutter
- Dart
- Android Studio / Visual Studio Code
